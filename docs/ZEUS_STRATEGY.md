# Liquid Wire Strategy

Liquid Wire is no longer a pet relaxation channel. The channel position is:

> Slow generative visuals, liquid wireframes, soft motion, and ambient
> soundscapes for focus, rest, and late-night calm.

## Publishing Rules

- Start with private uploads.
- Check Content ID before publishing.
- Do not use stock footage.
- Do not use downloaded music unless the license is explicit and auditable.
- Prefer procedural visuals and synthetic/local audio.

## Content Pillars

- Slowform ambient sessions
- Liquid wireframe studies
- Night drift visuals
- Focus loops
- Live tests
